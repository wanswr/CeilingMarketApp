# Отчет об оценке стоимости и потенциала CeilingsApp (Июнь 2026)

## 1. Резюме
Проведен глубокий анализ кодовой базы, архитектуры и рыночного позиционирования приложения CeilingsApp. Проект представляет собой высокотехнологичный MVP маркетплейса для узкой ниши (натяжные потолки) с потенциалом масштабирования на глобальный рынок.

---

## 2. Техническая себестоимость (Assets Evaluation)
Стоимость разработки аналогичного решения "с нуля" при привлечении Senior-специалистов:
*   **Объем кода:** ~18,000+ строк (React Native, NestJS, Prisma).
*   **Трудозатраты:** 800 – 1000 человеко-часов.
*   **Оценочная стоимость разработки:**
    *   Рынок СНГ: **$25,000 – $40,000**
    *   Глобальный рынок: **$60,000 – $90,000**

### Ключевые технологические активы:
1.  **MapEngine V9:** Собственный движок для работы с гео-данными, поддерживающий реактивную кластеризацию на стороне клиента и оптимизированные пространственные запросы.
2.  **Smart Parser:** Модуль эвристического анализа текста для автоматического создания заказов из неструктурированных данных (мессенджеры).
3.  **EntityStore:** Система нормализации и кеширования данных, обеспечивающая высокую производительность на мобильных устройствах.

---

## 3. Текущая рыночная стоимость (Asset Sale)
Стоимость проекта как программного актива (без учета базы пользователей и бренда) на текущий момент:
*   **Диапазон:** **$15,000 – $22,000**

### Факторы, влияющие на оценку:
*   **Плюсы:** Чистая архитектура, отсутствие легаси, готовность к нагрузкам до 1000 DAU без правок.
*   **Минусы (Дисконты):** Отсутствие SMS-авторизации, отсутствие полноценного медиа-сервера для фото, минимальное покрытие тестами.

---

## 4. Потенциал (Capitalization Growth)
При условии успешного запуска и набора критической массы пользователей (Liquidity):
*   **Через 1 год (СНГ):** **$150,000 – $300,000** (при выходе на 5,000+ заказов/мес).
*   **При выходе на Global (USA/UAE):** Оценка может вырасти в 5-10 раз за счет более высокого среднего чека и стоимости лида.

---

## 5. Рекомендации по увеличению стоимости
Для удвоения стоимости актива в кратчайшие сроки (14-30 дней) рекомендуется:
1.  **Hardening безопасности:** Интеграция реального SMS-шлюза (Twilio/SMSC).
2.  **Доверие и репутация:** Реализация системы отзывов и рейтингов.
3.  **Медиа-контент:** Интеграция с S3 (AWS/Selectel) для хранения фото работ.
4.  **Монетизация:** Активация модуля подписок, который уже заложен в архитектуру.
